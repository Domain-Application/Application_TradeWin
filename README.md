# Application_TradeWin

Weighbridge and trading system of TradeWin Metals Sdn Bhd: two-weight receiving and despatch, public weighing, scale weighing with unlimited product lines, tickets, purchase and sales invoices with an e-invoice panel and export to the accounts system, control tables (products with grade prices, accounts with e-invoice data, lorries, drivers, tax codes), reports and stock adjustment. Visual C++ 6 / MFC on the shared wlib32 library; project `menu.dsp`, main exe `menu.exe`; SQL Server database (no schema repo; connection data is in `PROVIDER.SYS`, which must not be copied into documents).
